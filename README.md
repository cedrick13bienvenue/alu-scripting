# ALU Scripting

Shell, Python, and scripting projects for the ALU Web Infrastructure track.

## Projects
| Project | Description |
| --- | --- |
| `api_advanced` | Python scripts that query the Reddit API: subscriber counts, hot post listings, pagination, and keyword counting |

## Resources
- [Reddit API Documentation](https://www.reddit.com/dev/api/)
- [Query String](https://en.wikipedia.org/wiki/Query_string)

## Learning Objectives
By the end of this project, you should be able to explain, without Google:
- How to read API documentation to find the endpoints you're looking for
- How to use an API with pagination
- How to parse JSON results from an API
- How to make a recursive API call
- How to sort a dictionary by value

## Requirements
- All files interpreted/compiled on Ubuntu 14.04 LTS using `python3` (version 3.4.3)
- All files end with a new line
- The first line of all files is exactly `#!/usr/bin/python3`
- Imports are organized in alphabetical order
- Code follows the PEP 8 style
- All files are executable
- All modules are documented
